# COS 201 – Java Programming

## About
This repository contains my Java programming coursework for COS 201. It includes basic Java programs and practical exercises created while learning Java.

## Topics Covered
- Introduction to Java
- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Methods
- Classes and Objects

## Requirements
- Java JDK installed
- A code editor such as VS Code or IntelliJ IDEA

## How to Run
1. Clone or download this repository.
2. Open the project in your code editor.
3. Compile the Java file:

   ```bash
   javac Main.java
   ```

4. Run the program:

   ```bash
   java Main
   ```
